# 📋 Digital Attendance Register

A modern, responsive web application designed to replace paper-based attendance logs. Built with a PHP backend, MySQL database, and a custom CSS interface featuring dynamic gradient themes and automated attendance tracking.

## ✨ Features

- **Automated Late Detection:** Calculates check-in timestamps on the server side and flags arrivals at or after 08:00 AM as **Late**.
- **Interactive Admin Dashboard:** Live attendance view displaying student records, total counts, on-time numbers, and late arrivals.
- **Dynamic Feedback Interface:** Animated glassmorphism confirmation cards providing real-time submission confirmation.
- **Database Management:** Prepared SQL queries with direct database reset capabilities for demo and testing environments.
- **Responsive Styling:** Custom CSS with multi-color animated gradients and interactive card layouts.

---

## 🛠️ Tech Stack

- **Front-End:** HTML5, CSS3 (Glassmorphism & CSS Animations), JavaScript
- **Back-End:** PHP 8.x
- **Database:** MySQL
- **Tooling:** XAMPP, Visual Studio Code, Git/GitHub
